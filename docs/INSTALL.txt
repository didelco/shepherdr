Install Shepherdr
================

Requires an Apple Silicon Mac (M1 or later) running macOS 14 Sonoma or later.

1. Drag Shepherdr.app to Applications.
2. Eject the Shepherdr disk image, then open Shepherdr from Applications.
   Shepherdr is signed with The Agile Monkeys' Developer ID and notarized by
   Apple, so macOS only asks you to confirm opening an app from the internet.

Required: install and start Herdr separately: https://herdr.dev/docs/
Shepherdr reads your existing Herdr installation and saved machine profiles.

Recommended: install the GitHub CLI (https://cli.github.com) and sign in with
"gh auth login". Shepherdr uses it to confirm pull requests and issues, fetch
their titles and watch pull requests' CI checks.

Pick a session in the sidebar to open its live terminal and send it the next
prompt. Switching sessions or quitting only detaches; Herdr keeps them running.
Interactive terminals require compatible Herdr terminal session commands
(verified with CLI/server 0.9.3). Xcode is not required to run Shepherdr.

Downloads and source: https://github.com/theam/shepherdr
Shepherdr is an independent client, not an official Herdr application.
