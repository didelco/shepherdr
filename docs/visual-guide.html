Shepherdr_

Una ventana de macOS para manejar todos tus agentes de código desde un solo sitio.

One macOS window to manage all your coding agents in one place.

Empezar

  1. Instala Herdr y arráncalo (CLI 0.9.3 o posterior para máquinas remotas y terminales).
  2. Descarga el .dmg de la última versión y arrastra Shepherdr.app a Aplicaciones.
  3. Está firmada con el Developer ID de The Agile Monkeys y notarizada por Apple, así que se abre como cualquier descarga. Una vez al día busca versiones nuevas y te ofrece actualizarse: comprueba la descarga y su firma, se cierra, se reemplaza y vuelve a abrirse.
  4. Pulsa ⌘N, elige la carpeta del proyecto y lanza tu agente en esa terminal. En unos segundos entra en la cola.
brew install herdr
herdr status

Requisitos: Mac con Apple Silicon y macOS 14 o posterior. Para compilarlo tú mismo: Xcode 16 o posterior, open Shepherdr.xcodeproj y ⌘R.

Si la cola sale vacía, mira primero herdr status: Shepherdr nunca arranca ni para el servidor.

Get started

  1. Install and start Herdr (CLI 0.9.3 or later for remote machines and terminals).
  2. Grab the .dmg from the latest release and drag Shepherdr.app to Applications.
  3. It's signed with The Agile Monkeys' Developer ID and notarized by Apple, so it opens like any other download. Once a day it looks for a new version and offers to update: it checks the download and its signature, quits, replaces itself and opens again.
  4. Press ⌘N, pick the project folder and start your agent in that terminal. It joins the queue within seconds.
brew install herdr
herdr status

Requirements: an Apple Silicon Mac with macOS 14 or later. To build it yourself: Xcode 16 or later, open Shepherdr.xcodeproj and ⌘R.

If the queue is empty, check herdr status first: Shepherdr never starts or stops the server.

Qué es

Agentes

Claude Code, Codex, Gemini, opencode… cada uno en su terminal.

Herdr

El motor. Mantiene las terminales vivas en segundo plano y detecta qué hace cada agente.

Shepherdr

La ventana. Cola por prioridad, la terminal de cada agente y avisos.

workingblocked: te necesitadoneidle

Herdr es un único binario en Rust que posee las terminales donde viven tus agentes. Si cierras el cliente o pierdes la conexión SSH, siguen trabajando. Marca cada panel como working, blocked o idle, y las máquinas locales y SSH comparten una sola lista de agentes.

Shepherdr es otra ventana a esas mismas sesiones: una app nativa de macOS que maneja la CLI herdr. No la envuelve, ni la sustituye, ni la incluye. Cerrar Shepherdr no detiene a los agentes.

What it is

Agents

Claude Code, Codex, Gemini, opencode… each in its own terminal.

Herdr

The engine. Keeps terminals alive in the background and detects what each agent is doing.

Shepherdr

The window. Priority queue, each agent's terminal, and alerts.

workingblocked: needs youdoneidle

Herdr is a single Rust binary that owns the terminals your agents live in. Close the client or lose your SSH connection and they keep working. It marks every pane as working, blocked or idle, and local and SSH machines share one agent list.

Shepherdr is another window onto those same sessions: a native macOS app that drives the herdr CLI. It doesn't wrap, replace or bundle it. Closing Shepherdr does not stop the agents.

Por qué otro cliente

Con unas decenas de agentes en marcha, cada uno con su rastro de pestañas (pull requests, artefactos de Claude…), hay muchas ovejas que pastorear. Shepherdr nació para ver de un vistazo qué agente te necesita y qué sesiones esperan a cuáles, y mantener arriba el trabajo importante.

Se creó con Claude, y gana funciones según se necesitan. No hay hoja de ruta, a propósito: la forma de trabajar con agentes cambia cada semana y la herramienta cambia con ella. Si te encaja, úsala. Si no, haz un fork o crea la tuya.

Why another client

With a few dozen agents running, each with its own trail of browser tabs (pull requests, Claude artifacts…), that's a lot of sheep to herd. Shepherdr was built to see at a glance which agent needs you and which sessions wait for which, and to keep the important work on top.

It was built with Claude, and gains features as they're needed. There's no roadmap, on purpose: the way of working with agents changes every week and the tool changes with it. If it fits, take it. If not, fork it or spawn your own.

Qué hace

  • Una cola para todos los agentes. Sesiones de todas tus máquinas, en tu orden de prioridad, con grupos y, si quieres, reunidas por proyecto.
  • La terminal real, embebida. Escribe en la TUI del agente; suelta ficheros e imágenes; usa el editor de prompts o dicta.
  • Un navegador por sesión. Los enlaces se abren junto a la terminal y las pestañas se conservan. Los ficheros locales también se abren.
  • Recursos a mano. PRs, issues y artefactos de Claude de cada sesión, en un panel lateral.
  • Sabes cuándo te toca. Un aviso cuando un agente termina o te necesita, con lo último que dijo.
  • Sesiones en espera. Un planificador espera a sus subagentes en un árbol plegable.
  • Conducir o solo mirar. Candado de solo lectura. Nunca le quita la entrada a otro cliente sin que lo pidas.
  • Crear y cerrar sesiones con ⌘N.
  • Compass, la página de tu día. Un agente propio la mantiene, y sus botones lanzan las sesiones que propone cuando tú las revisas.

Sin cuentas, sin telemetría, sin servidor. Los prompts, la salida de la terminal y tu voz nunca se escriben en disco, salvo el primer prompt de una sesión que lanzas desde Compass, que espera hasta que el agente lo recibe y entonces se borra. Solo se recuerdan tu cola y, por sesión, sus pestañas y enlaces; con Compass, también lo que muestra la cola, para su agente. El dictado se ejecuta por completo en tu Mac.

Features

  • One queue for every agent. Sessions from all your machines, in your own priority order, with groups and, if you like, gathered by project.
  • The real terminal, embedded. Type into the agent's TUI; drop files and images; use the prompt editor or dictate.
  • A browser per session. Links open next to the terminal and tabs stay put. Local files open too.
  • Resources at hand. The PRs, issues and Claude artifacts each session links to, in a side panel.
  • Know when it's your turn. An alert when an agent finishes or needs you, with what it last said.
  • Sessions on hold. A planner waits for its subagents in a collapsible tree.
  • Drive or just watch. Read-only padlock. It never steals input from another client unless you ask.
  • Create and close sessions with ⌘N.
  • Compass, the page of your day. An agent of its own keeps it, and its buttons start the sessions it suggests once you check them.

No accounts, no telemetry, no server. Prompts, terminal output and your voice never touch the disk, except the first prompt of a session you start from Compass, which waits until its agent takes it and is then deleted. Only your queue and, per session, its browser tabs and links are remembered; with Compass, also what the queue shows, for its agent. Dictation runs entirely on your Mac.

Conectar Herdr

Shepherdr consulta la sesión local por defecto de Herdr y lista los agentes que Herdr mismo reporta. Un panel de shell no es un agente: aparece en Shells y pasa a la cola en cuanto Herdr detecta un agente.

Busca herdr en /opt/homebrew/bin, /usr/local/bin, ~/.local/bin, ~/.cargo/bin y el PATH. Para una ruta propia, define SHEPHERDR_HERDR_PATH con la ruta absoluta.

Para el mejor estado de ciclo de vida, instala la integración de tu agente:

herdr integration install claude

Connect Herdr

Shepherdr queries Herdr's local default session and lists the agents Herdr itself reports. A shell pane is not an agent: it appears under Shells and moves into the queue as soon as Herdr detects an agent.

It looks for herdr in /opt/homebrew/bin, /usr/local/bin, ~/.local/bin, ~/.cargo/bin and your PATH. For a custom install, set SHEPHERDR_HERDR_PATH to the absolute path.

For the best lifecycle state, install your agent's integration:

La cola

La barra lateral es tu lista de sesiones, de todas las máquinas, en el orden que tú decidas. El número de cada fila es su prioridad. Cada fila muestra el workspace, qué hace el agente y dónde trabaja (la carpeta o, en un worktree de Git, el proyecto en cian), y el número de su pull request si la tiene.

  • Arrastra una sesión para moverla (una línea marca dónde caerá), usa las flechas ▲▼, ⌥⌘↑ y ⌥⌘↓, o Move to Top/Bottom en su menú.
  • Salta con ⌘1 … ⌘9, avanza con ⌘[ y ⌘], y vuelve al resumen con ⌘0.
  • ⌘T abre un buscador en el centro, como Spotlight: sesiones, shells y Compass, primero la última que visitaste. Escribe unas letras para filtrar y ⏎ para ir.
  • Las sesiones nuevas entran al final. Las prioridades se guardan en este Mac, siguen a la máquina y a la terminal, y no se sincronizan.

Grupos

Reúne sesiones como quieras (un proyecto, un cliente, trabajo personal). Un grupo ocupa una posición en la cola y se prioriza como una sola sesión; dentro, cada sesión conserva su orden.

  • Créalo con + group, con Session → New Group… o con Move to Group en el menú de una sesión.
  • Suelta una sesión sobre la cabecera para añadirla. Los grupos no se anidan.
  • Un grupo plegado sigue mostrando cuántas de sus sesiones te necesitan, y sus sesiones se saltan con ⌘1…⌘9.
  • + en la cabecera crea una sesión dentro del grupo. Ungroup nunca cierra sesiones.

Proyectos

Activa View → Gather Sessions by Project, o [ ] projects en la cabecera de la cola, para reunir bajo una cabecera las sesiones de cada proyecto (un repositorio de Git: su checkout principal y sus worktrees, en cualquier máquina), arriba en la cola y dentro de cada grupo. Viene desactivado.

  • La cabecera ocupa el lugar de la sesión más prioritaria del proyecto; una sesión sola sigue siendo una fila normal. Los números y ⌘1…⌘9 siguen lo que ves.
  • Bajo una cabecera, ▲▼ y arrastrar reordenan las sesiones del proyecto; las ▲▼ de la cabecera mueven el proyecto entero.
  • Haz clic en una cabecera para plegarla. Sigue mostrando cuántas de sus sesiones te necesitan.

The queue

The sidebar is your list of sessions, from all machines, in the order you choose. Each row's number is its priority. Each row shows the workspace, what the agent is doing, where it works (the folder or, for a Git worktree, its project in cyan), and its pull request number if it has one.

  • Drag a session to move it (a line shows where it lands), use the ▲▼ controls, ⌥⌘↑ and ⌥⌘↓, or Move to Top/Bottom in its menu.
  • Jump with ⌘1 … ⌘9, step with ⌘[ and ⌘], and return to the overview with ⌘0.
  • ⌘T opens a search panel in the middle, like Spotlight: sessions, shells and Compass, the one you visited last first. Type a few letters to narrow it and ⏎ to go.
  • New sessions join the end. Priorities are saved on this Mac, follow the machine and terminal, and aren't synchronized.

Groups

Gather sessions however you like (a project, a client, personal work). A group is one position in the queue and is prioritized like a single session; inside, each session keeps its own order.

  • Create one with + group, Session → New Group… or Move to Group in a session's menu.
  • Drop a session on a header to add it. Groups don't nest.
  • A collapsed group still shows how many of its sessions need you, and its sessions are skipped by ⌘1…⌘9.
  • + on the header creates a session in the group. Ungroup never closes sessions.

Projects

Turn on View → Gather Sessions by Project, or [ ] projects in the queue header, to gather each project's sessions (a Git repository: its main checkout and its worktrees, on any machine) under a heading, at the top of the queue and inside each group. It's off by default.

  • A heading sits where the project's highest-priority session was; a lone session stays a plain row. Numbers and ⌘1…⌘9 follow what you see.
  • Under a heading, ▲▼ and dragging reorder the project's sessions; the heading's ▲▼ move the whole project.
  • Click a heading to collapse it. It still shows how many of its sessions need you.

Trabajar con una sesión

Al seleccionarla se abre su terminal real en el área principal, con el teclado enfocado y la entrada activa.

  • Escribe directamente en la TUI del agente. ⇧⏎ añade una línea sin enviar. La barra inferior tiene teclas rápidas (Esc, ^C, Tab, flechas, Return).
  • ⌘L abre el editor de prompts, para textos largos. Guarda el borrador, ⏎ envía y ↑/↓ recuperan prompts de esa sesión.
  • Suelta ficheros o imágenes en la terminal para pegar su ruta; Claude Code y Codex adjuntan las imágenes. En una máquina remota se copian antes por SSH a ~/.cache/shepherdr/drops.
  • Haz clic en una opción de un menú numerado (permisos) para marcarla; doble clic para confirmar.
  • ⌘⎋ envía Escape para interrumpir. El candado (⌘E) deja la sesión en solo lectura.
  • Si otro cliente controla la terminal, queda bloqueada y se ofrece Take Over, siempre como decisión explícita.
  • Para que un agente escriba a otro, clic derecho en el ID del panel (w3:p1) → Copy Reference for Agents.
  • El botón de la carpeta en la cabecera, o ⇧⌘O, abre en Finder la carpeta donde trabaja el agente, si está en este Mac.
  • Haz clic en el nombre de otra sesión o en su ID de panel (w3:p1) en la terminal para ir a ella, como en lo que imprime shepherdr al lanzar una. nombre@máquina elige la máquina.

Crear y cerrar

⌘N abre New Session: una carpeta (en la máquina elegida) y un nombre opcional. New Session in Same Folder… la crea justo después de otra, en su grupo. IN A NEW WORKTREE la abre en un worktree de la rama que elijas, que Herdr crea en su carpeta de worktrees.

En lugar de una carpeta, pega un enlace de GitHub. Un repositorio abre tu clon, o lo clona antes en la carpeta de proyectos de esa máquina (~/projects; cada máquina tiene la suya en Settings). Un pull request abre un worktree de su rama, clonando el repositorio si hace falta, con el PR ya en Resources.

Rename… cambia el nombre del workspace. Close Session… pide confirmación y termina el proceso del agente; solo está en el menú contextual.

No hay scroll del histórico ni ratón dentro de apps de pantalla completa. Para eso usa el cliente herdr: comparte las sesiones.

Working with a session

Selecting one opens its real terminal in the main area, with keyboard focus and input enabled.

  • Type straight into the agent's TUI. ⇧⏎ adds a line without sending. The bottom bar has quick keys (Esc, ^C, Tab, arrows, Return).
  • ⌘L opens the prompt editor, for long text. It keeps your draft, ⏎ sends and ↑/↓ recall this session's prompts.
  • Drop files or images on the terminal to paste their paths; Claude Code and Codex attach images. On a remote machine they're first copied over SSH to ~/.cache/shepherdr/drops.
  • Click an option of a numbered menu (permissions) to select it; double-click to confirm.
  • ⌘⎋ sends Escape to interrupt. The padlock (⌘E) makes the session read-only.
  • If another client controls the terminal, it stays locked and offers Take Over, always an explicit choice.
  • To have one agent message another, right-click the pane ID (w3:p1) → Copy Reference for Agents.
  • The folder button in the header, or ⇧⌘O, opens the folder the agent works in, in Finder, when it's on this Mac.
  • Click another session's name or its pane ID (w3:p1) in the terminal to go to it, as in what shepherdr prints when it starts one. name@machine picks the machine.

Create and close

⌘N opens New Session: a folder (on the chosen machine) and an optional name. New Session in Same Folder… creates it right after another, in its group. IN A NEW WORKTREE opens it in a worktree of the branch you name, which Herdr creates in its worktrees folder.

Instead of a folder, paste a GitHub link. A repository opens your clone, or clones it first into that machine's projects folder (~/projects; each machine has its own in Settings). A pull request opens a worktree of its branch, cloning the repository if needed, with the PR already in Resources.

Rename… renames the workspace. Close Session… asks for confirmation and ends the agent process; it lives only in the context menu.

There's no scrollback browsing or mouse reporting inside full-screen apps. For that, use the herdr client: it shares the sessions.

Navegador y recursos

Cada sesión tiene su navegador junto a la terminal. Haz clic en un enlace y se abre ahí, en una pestaña nueva o en la que ya lo muestra; ⌘-clic usa tu navegador. ⌘B lo muestra u oculta. Las pestañas siguen cargadas al cambiar de sesión y vuelven tras reiniciar; una que no miras en 10 minutos suelta su página y la vuelve a cargar al mostrarla. Los inicios de sesión se comparten y persisten (los de Safari no se pueden reutilizar).

⌘? o ? al pie de la barra lateral abren esta guía en el navegador de la sesión que miras, o en el del resumen; Help → Herdr Documentation, la de Herdr.

Ficheros locales: haz clic en una ruta que imprime el agente. El Markdown se abre renderizado, el HTML como página y lo demás en su app por defecto.

Recursos

El panel RESOURCES reúne las PRs e issues (GitHub, GitLab, Bitbucket, Linear, Jira) y artefactos de Claude que enlaza la sesión: los diez más relevantes, y more para el resto. Cada recurso nuevo se comprueba una vez, y los que no existen desaparecen.

Checks de CI. Con la CLI de GitHub instalada y con sesión (gh auth login), Shepherdr vigila las PRs abiertas de la sesión que miras: ● corriendo, ✓ pasado, ✗ fallado. Al terminar, un aviso dice si pasaron.

Browser and resources

Each session has its browser next to the terminal. Click a link and it opens there, in a new tab or the one already showing it; ⌘-click uses your browser. ⌘B shows or hides it. Tabs stay loaded while you switch sessions and return after a restart; one you haven't looked at for 10 minutes lets go of its page and loads it again when shown. Sign-ins are shared and persist (Safari's can't be reused).

⌘? or ? at the foot of the sidebar opens this guide in the browser of the session you're viewing, or the overview's; Help → Herdr Documentation opens Herdr's.

Local files: click a path the agent prints. Markdown opens rendered, HTML as a page and anything else in its default app.

Resources

The RESOURCES panel gathers the PRs and issues (GitHub, GitLab, Bitbucket, Linear, Jira) and Claude artifacts a session links to: the ten most relevant, with more for the rest. Each new resource is checked once, and ones that don't exist leave the panel.

CI checks. With the GitHub CLI installed and signed in (gh auth login), Shepherdr watches the open PRs of the session you're viewing: ● running, ✓ passed, ✗ failed. When they finish, an alert says whether they passed.

Avisos, espera y dictado

Notificaciones

Cuando un agente termina o te necesita (un permiso, una pregunta), macOS te avisa con el nombre de la sesión, su estado y lo último que dijo. Haz clic para abrirla. La sesión que miras no avisa. Los avisos llegan al refrescar la cola (Settings → General → Refresh sessions: 5, 15, 30 o 60 s) y no llegan con el refresco en pausa. Con Shepherdr fuera de la vista (ventana oculta, pantalla apagada o bloqueada), las otras máquinas se consultan cada 30 s, así que sus avisos pueden tardar eso.

Sesiones en espera

Con Wait For… en el menú de una sesión, escribes unas letras de cada sesión que espera, por ejemplo los subagentes de un planificador, y la eliges con ↑/↓ y ⏎; @ filtra por máquina. Muestra un reloj de arena hasta que todas acaban, salvo que su agente trabaje o te necesite, que se ve antes. Las esperadas se cuelgan debajo en un árbol plegable, y las esperas se encadenan: si la esperada espera a su vez, la primera sigue en espera. Abrirla muestra un panel con sus estados; RESUME la saca de espera.

En el resumen, una sesión en espera cuenta como ON HOLD hasta que acaban las que espera, no como terminada: todas las vistas muestran el mismo estado. Una sesión que se cierra, desde Shepherdr o desde fuera, sale de las esperas a los 30 segundos. Si se espera a un shell, se espera al comando que ejecuta, como un script: al volver a su prompt, la espera termina sola. Las esperas se guardan en este Mac y, como copia, en Herdr, de donde las recupera un Mac nuevo.

Una sesión a la que otras esperan las lista en WAITED ON BY. Con las herramientas de agentes en su máquina, HANDOFF AND CLOSE pide a su agente, en cuanto esté libre, que les traspase su trabajo con shepherdr handoff, y cierra la sesión cuando el traspaso llega a Shepherdr. Si en 15 minutos no llega, sigue abierta.

Dictado

⇧⌘D empieza a grabar y abre el editor; al parar, la transcripción cae en el borrador para que la revises. Se transcribe en tu Mac con NVIDIA Parakeet TDT v3 (25 idiomas europeos, bueno con términos técnicos en inglés dentro de español). El modelo pesa unos 460 MB: Shepherdr pregunta antes de descargarlo la primera vez, y reutiliza el de scribe si ya lo tienes. Tu voz solo está en memoria mientras grabas.

Portátil

El pie de la barra lateral avisa si cerrar la tapa pausaría agentes que corren en este Mac. Los remotos no cuentan.

Alerts, hold and dictation

Notifications

When an agent finishes or needs you (a permission, a question), macOS notifies you with the session's name, its state and what it last said. Click to open it. The session you're viewing never notifies. Alerts arrive when the queue refreshes (Settings → General → Refresh sessions: 5, 15, 30 or 60 s) and don't arrive while refreshing is paused. While Shepherdr is out of sight (window hidden, displays asleep or locked), other machines are asked every 30 s, so their alerts can take that long.

Sessions on hold

With Wait For… in a session's menu, type a few letters of each session it waits for, such as a planner's subagents, and pick it with ↑/↓ and ⏎; @ narrows to a machine. It shows an hourglass until they all finish, unless its agent works or needs you, which shows first. The awaited ones hang below in a collapsible tree, and holds chain: if the awaited one waits in turn, the first keeps waiting. Opening it shows a panel with their states; RESUME takes it off hold.

In the overview, a session on hold counts as ON HOLD until the ones it waits for finish, not as done: every view shows the same status. A session that closes, from Shepherdr or elsewhere, drops out of holds after 30 seconds. Waiting for a shell means waiting for the command it runs, such as a script: once it's back at its prompt, the wait ends on its own. Holds are kept on this Mac and, as a copy, in Herdr, where a new Mac finds them.

A session others wait for lists them under WAITED ON BY. With the agent tools on its machine, HANDOFF AND CLOSE asks its agent, once it's free, to hand its work back to them with shepherdr handoff, and closes the session when the handoff reaches Shepherdr. If none comes within 15 minutes, it stays open.

Dictation

⇧⌘D starts recording and opens the editor; when you stop, the transcript lands in the draft for you to review. It's transcribed on your Mac with NVIDIA Parakeet TDT v3 (25 European languages, good with English technical terms inside Spanish). The model is about 460 MB: Shepherdr asks before downloading it the first time, and reuses scribe's copy if you have it. Your voice is only in memory while recording.

Máquinas remotas

Añade otro equipo y sus agentes aparecen en la misma cola. Necesitas SSH que autentique sin preguntar (carga la clave con ssh-add), un servidor de Herdr ya en marcha y Herdr 0.9.3 o posterior en ambos lados.

herdr machine add workbox --label "Build machine"
herdr machine add lab --label "Lab" --remote-session agents
herdr machine list --json

También en Settings → Machines (⌘,), donde puedes desactivarlas y ver los detalles de un fallo. Cada perfil es una sola sesión. Quitar una máquina solo olvida el perfil; sus sesiones siguen vivas. Si una falla, ves los últimos datos marcados como obsoletos.

Remote machines

Add another computer and its agents appear in the same queue. You need SSH that authenticates without prompting (load your key with ssh-add), a Herdr server already running and Herdr 0.9.3 or later on both ends.

herdr machine add workbox --label "Build machine"
herdr machine add lab --label "Lab" --remote-session agents
herdr machine list --json

Also in Settings → Machines (⌘,), where you can disable them and see failure details. Each profile is one session. Removing a machine only forgets the profile; its sessions keep running. If one fails, you see the last data marked stale.

Compass: la página de tu día

El primer modo de la ventana: COMPASS · AGENTS, junto a los botones de la ventana, o ⌥⌘1 y ⌥⌘2. Un agente propio en tu Mac mantiene una página con lo que merece tu atención, y su terminal está al lado para hablar con él todo el día. La pestaña COMPASS muestra un punto verde si la página cambió desde que la miraste, cian mientras se actualiza y ámbar si el agente te espera.

Empezar

Pulsa START COMPASS y elige el agente. Shepherdr crea ~/.shepherdr/compass, arranca el agente allí en un workspace de Herdr llamado compass, fuera de tu cola, y le pide la primera página. La primera vez, Claude Code pregunta si confías en la carpeta: responde en su terminal. Al principio solo resume tus sesiones: qué te necesita, qué terminó con sus PRs y checks, qué sigue en marcha y qué lleva días parado. Para que cubra más, como tu calendario o tu correo, pídeselo en su terminal: cambia su propio prompt.md. Si ya tienes una copia, pega su remoto de Git y pulsa RESTORE.

Cuándo se actualiza

Según Settings → Compass: solo cuando lo pides, una vez al día o cada cierto tiempo dentro de unas horas (cada hora de 9 a 18, de lunes a viernes, para empezar). ▶ RUN o ⌥⌘R la actualiza ya. Si el Mac durmió o Shepherdr estuvo cerrado y se saltó varias, se actualiza una vez al volver y espera a la siguiente; solo se recupera lo del mismo día. Si el Mac duerme o no tiene red, también espera: un agente que arrancara entonces pasaría el día sin sus conectores, como tu calendario o tu correo. Mientras escribes al agente, la actualización espera. Cada día empieza con un agente nuevo, y el resto del día va al mismo.

La página y sus botones

Todas las páginas salen de la plantilla de Shepherdr: fecha, titular, una franja del día con la línea de la hora que avanza sola, y las fuentes al pie. Lo de en medio lo decide el agente. Los botones nunca hacen nada sin ti: lanzar una sesión abre New Session con la máquina, la carpeta, el agente y el prompt ya puestos para que los revises, y la sesión le devuelve su resultado a Compass; preguntar deja el texto en el editor de Compass; abrir o escribir a una sesión te lleva a ella; hecho marca la tarea. Las sesiones que nombra la página muestran su estado en vivo. La columna de Compass guarda cada día y una copia por actualización.

Ficheros y copia

Todo está en ~/.shepherdr/compass: tu prompt.md y compass.json, que Shepherdr nunca pisa, el contrato y la plantilla, que sí actualiza, y una página por día. La carpeta es un repositorio de Git y cada actualización hace commit; con un remoto privado en Settings → Compass → Backup, Shepherdr hace push y te avisa si un remoto de GitHub es público. El agente ve lo que muestra tu cola, nunca lo que imprimió un terminal.

Compass: the page of your day

The window's first mode: COMPASS · AGENTS, beside the window's buttons, or ⌥⌘1 and ⌥⌘2. An agent of its own on your Mac keeps a page with what deserves your attention, and its terminal sits beside it so you can talk to it all day. The COMPASS tab shows a green dot when the page changed since you looked, cyan while it updates and amber when the agent waits for you.

Get started

Press START COMPASS and pick the agent. Shepherdr creates ~/.shepherdr/compass, starts the agent there in a Herdr workspace named compass, out of your queue, and asks it for the first page. The first time, Claude Code asks whether you trust the folder: answer in its terminal. At first it only sums up your sessions: what needs you, what finished with its pull requests and checks, what's in progress and what's been idle for days. For more, such as your calendar or your mail, ask it in its terminal: it changes its own prompt.md. If you have a backup already, paste its Git remote and press RESTORE.

When it updates

As set in Settings → Compass: only when you ask, once a day, or every so often within hours of the day (every hour from 9 to 18, Monday to Friday, to start with). ▶ RUN or ⌥⌘R updates it now. If the Mac slept or Shepherdr was closed through several updates, it updates once when it's back and waits for the next one; only the same day's are made up. If the Mac is asleep or offline, it waits too: an agent started then would go the day without its connectors, such as your calendar or mail. While you type to the agent, the update waits. Each day starts with a fresh agent, and the rest of the day goes to the same one.

The page and its buttons

Every page starts from Shepherdr's template: the date, a headline, a day strip whose time line moves on its own, and the sources at the foot. The agent decides what goes in between. Buttons never do anything without you: start a session opens New Session with the machine, folder, agent and prompt filled in for you to check, and the session hands its result back to Compass; ask puts the text in Compass's editor; open or prompt a session takes you to it; done marks the item. Sessions the page names show their state live. Compass's column keeps every day and a copy per update.

Files and backup

Everything is in ~/.shepherdr/compass: your prompt.md and compass.json, which Shepherdr never overwrites, the contract and template, which it keeps current, and one page per day. The folder is a Git repository and every update commits; with a private remote in Settings → Compass → Backup, Shepherdr pushes, and warns you if a GitHub remote is public. The agent sees what your queue shows, never what a terminal printed.

Consejos

  • Una sesión por tarea, con un nombre claro. Para trabajo en paralelo en el mismo repo, un worktree de Git por sesión.
  • Bloquea con el candado las que no miras, para no escribir en la equivocada.
  • Ordena por a quién desbloqueas primero: arriba, lo que frena a otros.
  • Escribe los encargos largos en el editor (⌘L), o dicta y revisa.
  • Ajusta el refresco a cómo trabajas: los avisos llegan con ese retraso.
  • Mantén el servidor siempre en marcha: lanza herdr al iniciar sesión.
  • Fuente de la terminal: Settings → General, cualquier fuente monoespaciada instalada.

Tips

  • One session per task, with a clear name. For parallel work in the same repo, one Git worktree per session.
  • Lock the sessions you're not watching, so you never type into the wrong one.
  • Order by whom you unblock first: what blocks others goes on top.
  • Write long requests in the editor (⌘L), or dictate and review.
  • Tune the refresh interval to how you work: alerts arrive with that delay.
  • Keep the server always running: launch herdr at login.
  • Terminal font: Settings → General, any installed monospaced font.

Si algo falla

  • La cola está vacía. Ejecuta herdr status. Si el servidor no corre, lanza herdr y pulsa ⌘R.
  • No puedo escribir. El candado está puesto, o hay otro cliente conectado. En ese caso usa Take Over.
  • Una máquina remota no conecta. Comprueba que ssh host entra sin pedir contraseña. Los detalles están en Settings → Machines.
  • No llegan notificaciones. Revisa Ajustes → General y los permisos de macOS. Dependen del intervalo de refresco.
  • macOS no deja abrir una versión antigua. Las anteriores a 0.8.4 no estaban notarizadas: Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente.
  • No veo los checks de las PRs. Necesitas gh auth status con sesión iniciada.

Troubleshooting

  • The queue is empty. Run herdr status. If the server isn't running, launch herdr and press ⌘R.
  • I can't type. The padlock is on, or another client is attached. In that case use Take Over.
  • A remote machine won't connect. Check that ssh host logs in without a password prompt. Details are in Settings → Machines.
  • No notifications. Check Settings → General and macOS permissions. They depend on the refresh interval.
  • macOS won't open an older version. Versions before 0.8.4 weren't notarized: System Settings → Privacy & Security → Open Anyway.
  • I don't see PR checks. You need gh auth status to show you're signed in.
