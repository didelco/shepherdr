Shepherdr_

Una ventana de macOS para manejar todos tus agentes de código desde un solo sitio.

One macOS window to manage all your coding agents in one place.

Empezar

  1. Instala Herdr y arráncalo (CLI 0.9.3 o posterior para máquinas remotas y terminales).
  2. Descarga el .dmg de la última versión y arrastra Shepherdr.app a Aplicaciones.
  3. Las versiones no están notarizadas por Apple. La primera vez: Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente.
  4. Pulsa ⌘N, elige la carpeta del proyecto y lanza tu agente en esa terminal. En unos segundos entra en la cola.
brew install herdr
herdr status

Requisitos: Mac con Apple Silicon y macOS 14 o posterior. Para compilarlo tú mismo: Xcode 16 o posterior, open Shepherdr.xcodeproj y ⌘R.

Si la cola sale vacía, mira primero herdr status: Shepherdr nunca arranca ni para el servidor.

Get started

  1. Install and start Herdr (CLI 0.9.3 or later for remote machines and terminals).
  2. Grab the .dmg from the latest release and drag Shepherdr.app to Applications.
  3. Builds aren't notarized by Apple. On first launch: System Settings → Privacy & Security → Open Anyway.
  4. Press ⌘N, pick the project folder and start your agent in that terminal. It joins the queue within seconds.
brew install herdr
herdr status

Requirements: an Apple Silicon Mac with macOS 14 or later. To build it yourself: Xcode 16 or later, open Shepherdr.xcodeproj and ⌘R.

If the queue is empty, check herdr status first: Shepherdr never starts or stops the server.

Qué es

Agentes

Claude Code, Codex, Gemini, opencode… cada uno en su terminal.

Herdr

El motor. Mantiene las terminales vivas en segundo plano y detecta qué hace cada agente.

Shepherdr

La ventana. Cola por prioridad, la terminal de cada agente y avisos.

workingblocked: te necesitadoneidle

Herdr es un único binario en Rust que posee las terminales donde viven tus agentes. Si cierras el cliente o pierdes la conexión SSH, siguen trabajando. Marca cada panel como working, blocked o idle, y las máquinas locales y SSH comparten una sola lista de agentes.

Shepherdr es otra ventana a esas mismas sesiones: una app nativa de macOS que maneja la CLI herdr. No la envuelve, ni la sustituye, ni la incluye. Cerrar Shepherdr no detiene a los agentes.

What it is

Agents

Claude Code, Codex, Gemini, opencode… each in its own terminal.

Herdr

The engine. Keeps terminals alive in the background and detects what each agent is doing.

Shepherdr

The window. Priority queue, each agent's terminal, and alerts.

workingblocked: needs youdoneidle

Herdr is a single Rust binary that owns the terminals your agents live in. Close the client or lose your SSH connection and they keep working. It marks every pane as working, blocked or idle, and local and SSH machines share one agent list.

Shepherdr is another window onto those same sessions: a native macOS app that drives the herdr CLI. It doesn't wrap, replace or bundle it. Closing Shepherdr does not stop the agents.

Por qué otro cliente

Con unas decenas de agentes en marcha, cada uno con su rastro de pestañas (pull requests, artefactos de Claude…), hay muchas ovejas que pastorear. Shepherdr nació para ver de un vistazo qué agente te necesita y qué sesiones esperan a cuáles, y mantener arriba el trabajo importante.

Se creó con Claude, y gana funciones según se necesitan. No hay hoja de ruta, a propósito: la forma de trabajar con agentes cambia cada semana y la herramienta cambia con ella. Si te encaja, úsala. Si no, haz un fork o crea la tuya.

Why another client

With a few dozen agents running, each with its own trail of browser tabs (pull requests, Claude artifacts…), that's a lot of sheep to herd. Shepherdr was built to see at a glance which agent needs you and which sessions wait for which, and to keep the important work on top.

It was built with Claude, and gains features as they're needed. There's no roadmap, on purpose: the way of working with agents changes every week and the tool changes with it. If it fits, take it. If not, fork it or spawn your own.

Qué hace

  • Una cola para todos los agentes. Sesiones de todas tus máquinas, en tu orden de prioridad, con grupos.
  • La terminal real, embebida. Escribe en la TUI del agente; suelta ficheros e imágenes; usa el editor de prompts o dicta.
  • Un navegador por sesión. Los enlaces se abren junto a la terminal y las pestañas se conservan. Los ficheros locales también se abren.
  • Recursos a mano. PRs, issues y artefactos de Claude de cada sesión, en un panel lateral.
  • Sabes cuándo te toca. Un aviso cuando un agente termina o te necesita, con lo último que dijo.
  • Sesiones en espera. Un planificador espera a sus subagentes en un árbol plegable.
  • Conducir o solo mirar. Candado de solo lectura. Nunca le quita la entrada a otro cliente sin que lo pidas.
  • Crear y cerrar sesiones con ⌘N.

Sin cuentas, sin telemetría, sin servidor. Los prompts, la salida de la terminal y tu voz nunca se escriben en disco. Solo se recuerdan tu cola y, por sesión, sus pestañas y enlaces. El dictado se ejecuta por completo en tu Mac.

Features

  • One queue for every agent. Sessions from all your machines, in your own priority order, with groups.
  • The real terminal, embedded. Type into the agent's TUI; drop files and images; use the prompt editor or dictate.
  • A browser per session. Links open next to the terminal and tabs stay put. Local files open too.
  • Resources at hand. The PRs, issues and Claude artifacts each session links to, in a side panel.
  • Know when it's your turn. An alert when an agent finishes or needs you, with what it last said.
  • Sessions on hold. A planner waits for its subagents in a collapsible tree.
  • Drive or just watch. Read-only padlock. It never steals input from another client unless you ask.
  • Create and close sessions with ⌘N.

No accounts, no telemetry, no server. Prompts, terminal output and your voice never touch the disk. Only your queue and, per session, its browser tabs and links are remembered. Dictation runs entirely on your Mac.

Conectar Herdr

Shepherdr consulta la sesión local por defecto de Herdr y lista los agentes que Herdr mismo reporta. Un panel de shell no es un agente: aparece en Shells y pasa a la cola en cuanto Herdr detecta un agente.

Busca herdr en /opt/homebrew/bin, /usr/local/bin, ~/.local/bin, ~/.cargo/bin y el PATH. Para una ruta propia, define SHEPHERDR_HERDR_PATH con la ruta absoluta.

Para el mejor estado de ciclo de vida, instala la integración de tu agente:

herdr integration install claude

Connect Herdr

Shepherdr queries Herdr's local default session and lists the agents Herdr itself reports. A shell pane is not an agent: it appears under Shells and moves into the queue as soon as Herdr detects an agent.

It looks for herdr in /opt/homebrew/bin, /usr/local/bin, ~/.local/bin, ~/.cargo/bin and your PATH. For a custom install, set SHEPHERDR_HERDR_PATH to the absolute path.

For the best lifecycle state, install your agent's integration:

herdr integration install claude

La cola

La barra lateral es tu lista de sesiones, de todas las máquinas, en el orden que tú decidas. El número de cada fila es su prioridad. Cada fila muestra el workspace, qué hace el agente y dónde trabaja (la carpeta o, en un worktree de Git, el proyecto en cian), y el número de su pull request si la tiene.

  • Arrastra una sesión para moverla (una línea marca dónde caerá), usa las flechas ▲▼, ⌥⌘↑ y ⌥⌘↓, o Move to Top/Bottom en su menú.
  • Salta con ⌘1 … ⌘9, avanza con ⌘[ y ⌘], y vuelve al resumen con ⌘0.
  • Filtra con ⌘F. Puedes reordenar mientras filtras: las sesiones ocultas conservan su hueco.
  • Las sesiones nuevas entran al final. Las prioridades se guardan en este Mac, siguen a la máquina y a la terminal, y no se sincronizan.

Grupos

Reúne sesiones como quieras (un proyecto, un cliente, trabajo personal). Un grupo ocupa una posición en la cola y se prioriza como una sola sesión; dentro, cada sesión conserva su orden.

  • Créalo con + group, con Session → New Group… o con Move to Group en el menú de una sesión.
  • Suelta una sesión sobre la cabecera para añadirla. Los grupos no se anidan.
  • Un grupo plegado sigue mostrando cuántas de sus sesiones te necesitan, y sus sesiones se saltan con ⌘1…⌘9.
  • + en la cabecera crea una sesión dentro del grupo. Ungroup nunca cierra sesiones.

The queue

The sidebar is your list of sessions, from all machines, in the order you choose. Each row's number is its priority. Each row shows the workspace, what the agent is doing, where it works (the folder or, for a Git worktree, its project in cyan), and its pull request number if it has one.

  • Drag a session to move it (a line shows where it lands), use the ▲▼ controls, ⌥⌘↑ and ⌥⌘↓, or Move to Top/Bottom in its menu.
  • Jump with ⌘1 … ⌘9, step with ⌘[ and ⌘], and return to the overview with ⌘0.
  • Filter with ⌘F. You can reorder while filtering: hidden sessions keep their slots.
  • New sessions join the end. Priorities are saved on this Mac, follow the machine and terminal, and aren't synchronized.

Groups

Gather sessions however you like (a project, a client, personal work). A group is one position in the queue and is prioritized like a single session; inside, each session keeps its own order.

  • Create one with + group, Session → New Group… or Move to Group in a session's menu.
  • Drop a session on a header to add it. Groups don't nest.
  • A collapsed group still shows how many of its sessions need you, and its sessions are skipped by ⌘1…⌘9.
  • + on the header creates a session in the group. Ungroup never closes sessions.

Trabajar con una sesión

Al seleccionarla se abre su terminal real en el área principal, con el teclado enfocado y la entrada activa.

  • Escribe directamente en la TUI del agente. ⇧⏎ añade una línea sin enviar. La barra inferior tiene teclas rápidas (Esc, ^C, Tab, flechas, Return).
  • ⌘L abre el editor de prompts, para textos largos. Guarda el borrador, ⏎ envía y ↑/↓ recuperan prompts de esa sesión.
  • Suelta ficheros o imágenes en la terminal para pegar su ruta; Claude Code y Codex adjuntan las imágenes. En una máquina remota se copian antes por SSH a ~/.cache/shepherdr/drops.
  • Haz clic en una opción de un menú numerado (permisos) para marcarla; doble clic para confirmar.
  • ⌘⎋ envía Escape para interrumpir. El candado (⌘E) deja la sesión en solo lectura.
  • Si otro cliente controla la terminal, queda bloqueada y se ofrece Take Over, siempre como decisión explícita.
  • Para que un agente escriba a otro, clic derecho en el ID del panel (w3:p1) → Copy Reference for Agents.

Crear y cerrar

⌘N abre New Session: una carpeta (en la máquina elegida) y un nombre opcional. New Session in Same Folder… la crea justo después de otra, en su grupo. Rename… cambia el nombre del workspace. Close Session… pide confirmación y termina el proceso del agente; solo está en el menú contextual.

No hay scroll del histórico ni ratón dentro de apps de pantalla completa. Para eso usa el cliente herdr: comparte las sesiones.

Working with a session

Selecting one opens its real terminal in the main area, with keyboard focus and input enabled.

  • Type straight into the agent's TUI. ⇧⏎ adds a line without sending. The bottom bar has quick keys (Esc, ^C, Tab, arrows, Return).
  • ⌘L opens the prompt editor, for long text. It keeps your draft, ⏎ sends and ↑/↓ recall this session's prompts.
  • Drop files or images on the terminal to paste their paths; Claude Code and Codex attach images. On a remote machine they're first copied over SSH to ~/.cache/shepherdr/drops.
  • Click an option of a numbered menu (permissions) to select it; double-click to confirm.
  • ⌘⎋ sends Escape to interrupt. The padlock (⌘E) makes the session read-only.
  • If another client controls the terminal, it stays locked and offers Take Over, always an explicit choice.
  • To have one agent message another, right-click the pane ID (w3:p1) → Copy Reference for Agents.

Create and close

⌘N opens New Session: a folder (on the chosen machine) and an optional name. New Session in Same Folder… creates it right after another, in its group. Rename… renames the workspace. Close Session… asks for confirmation and ends the agent process; it lives only in the context menu.

There's no scrollback browsing or mouse reporting inside full-screen apps. For that, use the herdr client: it shares the sessions.

Navegador y recursos

Cada sesión tiene su navegador junto a la terminal. Haz clic en un enlace y se abre ahí, en una pestaña nueva o en la que ya lo muestra; ⌘-clic usa tu navegador. ⌘B lo muestra u oculta. Las pestañas siguen cargadas al cambiar de sesión y vuelven tras reiniciar. Los inicios de sesión se comparten y persisten (los de Safari no se pueden reutilizar).

Ficheros locales: haz clic en una ruta que imprime el agente. El Markdown se abre renderizado, el HTML como página y lo demás en su app por defecto.

Recursos

El panel RESOURCES reúne las PRs e issues (GitHub, GitLab, Bitbucket, Linear, Jira) y artefactos de Claude que enlaza la sesión: los diez más relevantes, y more para el resto. Cada recurso nuevo se comprueba una vez, y los que no existen desaparecen.

Checks de CI. Con la CLI de GitHub instalada y con sesión (gh auth login), Shepherdr vigila las PRs abiertas de la sesión que miras: ● corriendo, ✓ pasado, ✗ fallado. Al terminar, un aviso dice si pasaron.

Browser and resources

Each session has its browser next to the terminal. Click a link and it opens there, in a new tab or the one already showing it; ⌘-click uses your browser. ⌘B shows or hides it. Tabs stay loaded while you switch sessions and return after a restart. Sign-ins are shared and persist (Safari's can't be reused).

Local files: click a path the agent prints. Markdown opens rendered, HTML as a page and anything else in its default app.

Resources

The RESOURCES panel gathers the PRs and issues (GitHub, GitLab, Bitbucket, Linear, Jira) and Claude artifacts a session links to: the ten most relevant, with more for the rest. Each new resource is checked once, and ones that don't exist leave the panel.

CI checks. With the GitHub CLI installed and signed in (gh auth login), Shepherdr watches the open PRs of the session you're viewing: ● running, ✓ passed, ✗ failed. When they finish, an alert says whether they passed.

Avisos, espera y dictado

Notificaciones

Cuando un agente termina o te necesita (un permiso, una pregunta), macOS te avisa con el nombre de la sesión, su estado y lo último que dijo. Haz clic para abrirla. La sesión que miras no avisa. Los avisos llegan al refrescar la cola (Settings → General → Refresh sessions: 5, 15, 30 o 60 s) y no llegan con el refresco en pausa.

Sesiones en espera

Con Wait For en el menú de una sesión, eliges las que espera, por ejemplo los subagentes de un planificador. Muestra un reloj de arena: azul mientras alguna siga trabajando, verde cuando todas acaben. Las esperadas se cuelgan debajo en un árbol plegable. Abrirla muestra un panel con sus estados; RESUME la saca de espera.

Dictado

⇧⌘D empieza a grabar y abre el editor; al parar, la transcripción cae en el borrador para que la revises. Se transcribe en tu Mac con NVIDIA Parakeet TDT v3 (25 idiomas europeos, bueno con términos técnicos en inglés dentro de español). El modelo pesa unos 460 MB: Shepherdr pregunta antes de descargarlo la primera vez, y reutiliza el de scribe si ya lo tienes. Tu voz solo está en memoria mientras grabas.

Portátil

El pie de la barra lateral avisa si cerrar la tapa pausaría agentes que corren en este Mac. Los remotos no cuentan.

Alerts, hold and dictation

Notifications

When an agent finishes or needs you (a permission, a question), macOS notifies you with the session's name, its state and what it last said. Click to open it. The session you're viewing never notifies. Alerts arrive when the queue refreshes (Settings → General → Refresh sessions: 5, 15, 30 or 60 s) and don't arrive while refreshing is paused.

Sessions on hold

With Wait For in a session's menu, pick the sessions it waits for, such as a planner's subagents. It shows an hourglass: blue while any is still working, green once all have finished. The awaited ones hang below in a collapsible tree. Opening it shows a panel with their states; RESUME takes it off hold.

Dictation

⇧⌘D starts recording and opens the editor; when you stop, the transcript lands in the draft for you to review. It's transcribed on your Mac with NVIDIA Parakeet TDT v3 (25 European languages, good with English technical terms inside Spanish). The model is about 460 MB: Shepherdr asks before downloading it the first time, and reuses scribe's copy if you have it. Your voice is only in memory while recording.

Laptop

The foot of the sidebar tells you whether closing the lid would pause agents running on this Mac. Remote ones don't count.

Máquinas remotas

Añade otro equipo y sus agentes aparecen en la misma cola. Necesitas SSH que autentique sin preguntar (carga la clave con ssh-add), un servidor de Herdr ya en marcha y Herdr 0.9.3 o posterior en ambos lados.

herdr machine add workbox --label "Build machine"
herdr machine add lab --label "Lab" --remote-session agents
herdr machine list --json

También en Settings → Machines (⌘,), donde puedes desactivarlas y ver los detalles de un fallo. Cada perfil es una sola sesión. Quitar una máquina solo olvida el perfil; sus sesiones siguen vivas. Si una falla, ves los últimos datos marcados como obsoletos.

Remote machines

Add another computer and its agents appear in the same queue. You need SSH that authenticates without prompting (load your key with ssh-add), a Herdr server already running and Herdr 0.9.3 or later on both ends.

herdr machine add workbox --label "Build machine"
herdr machine add lab --label "Lab" --remote-session agents
herdr machine list --json

Also in Settings → Machines (⌘,), where you can disable them and see failure details. Each profile is one session. Removing a machine only forgets the profile; its sessions keep running. If one fails, you see the last data marked stale.

Consejos

  • Una sesión por tarea, con un nombre claro. Para trabajo en paralelo en el mismo repo, un worktree de Git por sesión.
  • Bloquea con el candado las que no miras, para no escribir en la equivocada.
  • Ordena por a quién desbloqueas primero: arriba, lo que frena a otros.
  • Escribe los encargos largos en el editor (⌘L), o dicta y revisa.
  • Ajusta el refresco a cómo trabajas: los avisos llegan con ese retraso.
  • Mantén el servidor siempre en marcha: lanza herdr al iniciar sesión.
  • Fuente de la terminal: Settings → General, cualquier fuente monoespaciada instalada.

Tips

  • One session per task, with a clear name. For parallel work in the same repo, one Git worktree per session.
  • Lock the sessions you're not watching, so you never type into the wrong one.
  • Order by whom you unblock first: what blocks others goes on top.
  • Write long requests in the editor (⌘L), or dictate and review.
  • Tune the refresh interval to how you work: alerts arrive with that delay.
  • Keep the server always running: launch herdr at login.
  • Terminal font: Settings → General, any installed monospaced font.

Si algo falla

  • La cola está vacía. Ejecuta herdr status. Si el servidor no corre, lanza herdr y pulsa ⌘R.
  • No puedo escribir. El candado está puesto, o hay otro cliente conectado. En ese caso usa Take Over.
  • Una máquina remota no conecta. Comprueba que ssh host entra sin pedir contraseña. Los detalles están en Settings → Machines.
  • No llegan notificaciones. Revisa Ajustes → General y los permisos de macOS. Dependen del intervalo de refresco.
  • macOS no deja abrir la app. Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente.
  • No veo los checks de las PRs. Necesitas gh auth status con sesión iniciada.

Troubleshooting

  • The queue is empty. Run herdr status. If the server isn't running, launch herdr and press ⌘R.
  • I can't type. The padlock is on, or another client is attached. In that case use Take Over.
  • A remote machine won't connect. Check that ssh host logs in without a password prompt. Details are in Settings → Machines.
  • No notifications. Check Settings → General and macOS permissions. They depend on the refresh interval.
  • macOS won't open the app. System Settings → Privacy & Security → Open Anyway.
  • I don't see PR checks. You need gh auth status to show you're signed in.
